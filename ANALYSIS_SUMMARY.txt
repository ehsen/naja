## 💡 Key Insights

1. **Low-Hanging Fruit:** Win32ListdirTests and Win32JunctionTests are ~95% ready. Minimal work.

2. **Quick Win:** Phase 1 (9 hours) gives you ~30% coverage with immediate value.

3. **Good ROI:** Phase 1+2 (24 hours) gives you ~75% coverage - best bang for buck.

4. **Expensive:** Phase 3 (ctypes) is NOT recommended unless absolutely required. It's 50+ hours.

5. **Safe Architecture:** All new code is Windows-conditional → won't break non-Windows builds.

6. **Clear Pattern:** Follows existing JsonTests.cs and Win32OsTests.cs patterns → maintainable.

---

## ⚠️ Critical Decisions

1. **ctypes Deferred:** Phase 3 is optional. Phases 1+2 alone give 76% coverage without ctypes.

2. **Test Data File:** Will be pure Python in `testdata/windows_os/test_windows.py` (not C#).

3. **Skip Logic:** Tests will use inline `self.skipTest()` instead of decorators for simplicity.

4. **WinAPI Approach:** Will use P/Invoke where needed, fsutil.exe subprocess fallback for complex queries.

5. **Platform Safety:** All Windows-specific code wrapped in `if (OperatingSystem.IsWindows())` checks.
