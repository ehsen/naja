ARCHITECTURE
============
Before: Single 1551-line monolith with 25 statement types mixed
After:  Dispatcher + 5 specialists + utilities

StatementEmitter dispatcher routes:
- Assignments → AssignmentEmitters
- Control Flow (if/while/for/break/continue) → ControlFlowEmitters  
- Exceptions (try/raise/assert/with) → ExceptionEmitters
- Definitions (function/class) → DefinitionEmitters
- Scope (nonlocal/return/expression) → ScopeEmitters

Each specialist inherits from StatementEmitterBase for shared utilities.
Lazy properties ensure unused specialists aren't allocated.
