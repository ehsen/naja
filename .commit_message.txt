refactor: establish codebase organization foundation (Phase 1-2)

This commit implements Phase 1-2 of the comprehensive Naja compiler refactoring
plan to break down monolithic files into focused, maintainable modules.

## Created Files

### Directory Structure
- Naja.CodeGen/Emitters/Expressions/     - Expression emission specialists
- Naja.CodeGen/Emitters/Statements/      - Statement emission specialists  
- Naja.CodeGen/Emitters/Assembly/        - Assembly emission specialists
- Naja.CodeGen/Builtins/                 - Builtin function modules

### Base Classes
- ExpressionEmitterBase.cs - Shared IL utilities for expression emitters
- StatementEmitterBase.cs - Shared utilities for statement emitters

### Expression Specialists
- LiteralEmitters.cs - Int, Float, String, Bool, None, Ellipsis
- CollectionEmitters.cs - List, Tuple, Dict, Set

### Builtin Modules
- DynamicOperators.cs - Dynamic arithmetic with dunder dispatch
- Collections.cs - len, range, enumerate, zip, map, filter, etc.
- ComparisonOperators.cs - Dynamic comparisons with containers

## Design Pattern
Established specialist emitter pattern for scalable extraction:
- Each module 150-250 lines (vs 1500-2400 lines)
- Single responsibility
- Dependency injection of EmitContext
- Shared base class utilities
- Zero breaking changes to existing APIs
